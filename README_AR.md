# Knowledge Without Borders — المعرفة بلا حدود

**اجمع المعرفة. احفظ الحكمة. شارك بلا حدود.**

**الإصدار الحالي:** 0.2.1
**المنصة الحالية:** Windows x64

[تنزيل أحدث إصدار](https://github.com/aboalmaty/knowledge-without-borders/releases/latest) · [الدليل الإنجليزي](README.md) · [سجل التغييرات](CHANGELOG.md)

## ما هو البرنامج؟

«المعرفة بلا حدود» (KWB) تطبيق سطح مكتب متعدد اللغات، يعتمد على التخزين المحلي، ويساعد الباحثين والطلاب والمعلمين والمهتمين بالمعرفة على جمع الفوائد والمعلومات، وتنظيمها والبحث فيها، وحفظ بيانات مصادرها، وإدارة سجلات ترجماتها، وتبادل مجموعات مختارة منها.

يعامل البرنامج كل فائدة باعتبارها سجلًا معرفيًا مستقلًا يمكن ربطه بتصنيف وبيانات مصدر ونسبة، ثم تصديره أو استيراده ضمن مكتبة معرفية.

## الخصائص المتاحة في الإصدار 0.2.1

### تنظيم المكتبة المعرفية

- إنشاء التصنيفات الرئيسية والفرعية وتعديلها، وحذف التصنيف الخالي.
- إضافة الفوائد وتحريرها وحذفها.
- تسجيل بيانات المؤلف والكتاب والمجلد والصفحة ولغة النص الأصلي وصاحب الفائدة.
- محرر نصوص يدعم التنسيق الأساسي والقوائم والاقتباسات واختيار نوع الخط وحجمه ولون النص ولون تمييز الخلفية.
- لوحة معلومات تعرض نشاط المكتبة وتوزيع الفوائد على التصنيفات.
- أربعة ثيمات: فاتح، وداكن، وورقي دافئ، وأخضر هادئ.
- التحكم في مقياس عناصر الواجهة وحجم النصوص مع حفظ التفضيلات محليًا.

### البحث واللغات

- البحث في عناوين الفوائد ومحتواها وحقول المؤلف والكتاب وصاحب الفائدة.
- بحث نصي محلي يتضمن تطبيعًا أوليًا لبعض صور الحروف العربية، وإزالة التشكيل والتطويل.
- واجهة بست لغات: العربية والإنجليزية والإسبانية والفرنسية والصينية والأوردية.
- يتحول اتجاه الواجهة تلقائيًا إلى RTL للعربية والأوردية، وإلى LTR لبقية اللغات.
- حفظ سجلات ترجمة مرتبطة بالفائدة الأصلية، مع لغة الترجمة واسم المترجم وحالة الترجمة.
- لا تقتصر لغة الفائدة أو الترجمة على لغات واجهة البرنامج الست؛ يمكن إدخال رمز أو اسم لغة أخرى.

> إدارة سجلات الترجمات وحفظها ومراجعتها متاحة، لكن لم يتم بعد ربط البرنامج بمزود ترجمة آلية.

### تبادل الفوائد والمكتبات

- إنشاء ملف مشاركة بامتداد `.kwb` للفوائد المحددة، مع التصنيفات اللازمة وسجلات الترجمات.
- استيراد ملفات `.kwb` مع الحفاظ على معرفات الفوائد وبيانات المصادر المتاحة.
- فتح WhatsApp Web وTelegram Web وMessenger من شاشة التبادل. ينشئ المستخدم ملف المشاركة أولًا، ثم يرفقه ويرسله يدويًا من تطبيق المراسلة؛ لا يرسل البرنامج المرفق تلقائيًا.

### التخزين المحلي والخصوصية

- تُخزَّن مكتبة سطح المكتب في قاعدة بيانات SQLite محلية.
- تعمل إدارة المكتبة والبحث النصي دون الحاجة إلى اتصال بالإنترنت.
- لا يلزم إنشاء حساب سحابي لاستخدام المكتبة المحلية.

## تنزيل البرنامج

يمكن تنزيل مثبتات Windows x64 من صفحة [أحدث إصدار على GitHub](https://github.com/aboalmaty/knowledge-without-borders/releases/latest):

- مثبت Windows بصيغة EXE (NSIS).
- مثبت Windows بصيغة MSI.

احتفظ بنسخة احتياطية من مكتبتك قبل تثبيت أي تحديث. يمكن تثبيت الإصدار الجديد فوق الإصدار السابق، ولا تحذف مجلد بيانات التطبيق يدويًا.

| الإنجليزية | LTR |
| الإسبانية | LTR |
| الفرنسية | LTR |
| الصينية | LTR |
| الأوردية | RTL |

## ما الذي لم يكتمل بعد؟

البرنامج قيد التطوير، وتشمل الأعمال المخطط لها أو غير المتاحة في الإصدار الحالي:

1. **الترجمة الآلية:** لم يتم ربط مزود ترجمة آلية بعد. ستحتاج موصلات الترجمة السحابية مستقبلًا إلى اتصال بالإنترنت، مع توضيح ما يُرسل إلى الخدمة وإتاحة ضبط الموصل أو تعطيله.
2. **المرفقات:** لا توجد حاليًا إدارة مدمجة لملفات PDF والصور والمرفقات، ولا تُضمّن هذه الملفات في حزم KWB.
3. **معاينة الاستيراد وحل التعارضات المتقدم:** سلوك الاستيراد الحالي أساسي؛ يطابق التصنيفات وفق الاسم والأب عند الحاجة، ويتجاوز الفائدة الموجودة مسبقًا إذا تكرر معرفها. لم تُضف بعد شاشة تفصيلية لاختيار الدمج أو الاحتفاظ أو التجاوز.
4. **البحث الدلالي:** البحث الحالي نصي محلي وليس محرك بحث دلاليًا أو متعدد اللغات قائمًا على المتجهات.
5. **المزامنة والمكتبات المشتركة:** لا تتوفر مزامنة تلقائية بين الأجهزة أو مكتبات مشتركة مباشرة في الإصدار الحالي.
6. **التطبيقات المحمولة ومساحات العمل التعاونية:** ليست متاحة في هذا الإصدار.
7. **تشفير ملفات التبادل:** ملف `.kwb` الحالي عبارة عن JSON منظم بامتداد خاص، وهو غير مشفر ولا يتضمن مرفقات. لا تضع فيه معلومات حساسة ما لم تقم بحمايتها بصورة مستقلة.

## تشغيل نسخة التطوير على Windows

### المتطلبات

- Windows 10 أو Windows 11.
- Node.js بإصدار LTS وnpm.
- Rust مع أداة `rustup` واختيار MSVC: `rustup default stable-msvc`.
- Microsoft C++ Build Tools، مع تحديد workload باسم **Desktop development with C++**.
- WebView2 Runtime.

راجع [متطلبات Tauri الرسمية](https://v2.tauri.app/start/prerequisites/) قبل تجهيز بيئة التطوير.

### التشغيل كتطبيق سطح مكتب

```powershell
npm install
npm run tauri dev
```

أو شغّل `run-dev.bat` من مجلد المشروع.

### بناء مثبتات Windows

```powershell
npm install
npm run tauri build
```

أو شغّل `build-windows.bat`. ستجد ملفات التثبيت الناتجة ضمن:

```text
src-tauri/target/release/bundle/nsis/
src-tauri/target/release/bundle/msi/
```

### معاينة الواجهة في المتصفح

```powershell
npm install
npm run dev
```

ثم افتح `http://127.0.0.1:1420`. وضع المعاينة في المتصفح يستخدم `localStorage` للمعاينة فقط، ولا يستخدم قاعدة SQLite الخاصة بتطبيق سطح المكتب.

## قاعدة البيانات والخصوصية

- تُنشأ قاعدة SQLite تلقائيًا في مجلد بيانات التطبيق الذي يحدده نظام التشغيل، وليس داخل مجلد التثبيت.
- لا يحتاج تشغيل البرنامج أو البحث أو إدارة المكتبة المحلية إلى الإنترنت.
- فتح مواقع/تطبيقات المراسلة يحتاج اتصالًا بالإنترنت.
- الترجمة السحابية غير مفعّلة في الإصدار الحالي؛ وعند إضافة موصلات لها مستقبلًا ستحتاج إلى الإنترنت.
- ملف `.kwb` في الإصدار الحالي ملف JSON منظم بامتداد خاص؛ لا يحتوي على تشفير أو مرفقات.
- يُنصح بالاحتفاظ بنسخ احتياطية آمنة من المكتبة وملفات التبادل، وعدم حذف مجلد بيانات التطبيق يدويًا.

## حالة بناء الإصدار 0.2.1

- نجح بناء تطبيق Windows x64 باستخدام Tauri وRust وVite 8.3.6.
- تم توليد مثبت Windows بصيغتي EXE وMSI.
- أظهر `npm audit` عدم وجود ثغرات معروفة في تبعيات npm وقت الفحص.
- أظهر `cargo audit` تحذيرين في تبعيات Rust هما `proc-macro-error` (غير مستمرة الصيانة) و`glib` (تحذير سلامة). ترتبط هذه التبعيات بمسار GTK المستخدم في بناء Linux؛ لذلك يلزم تقييمها واختبارها قبل تقديم دعم Linux.
