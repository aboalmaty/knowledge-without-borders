## ما الذي يتضمنه هذا الإصدار؟

- واجهة بست لغات: العربية، الإنجليزية، الإسبانية، الفرنسية، الصينية، والأوردية.
- تحويل اتجاه الواجهة تلقائيًا بين RTL للعربية والأوردية وLTR لبقية اللغات.
- قاعدة بيانات SQLite محلية داخل مجلد بيانات التطبيق، وليست داخل مجلد تثبيته.
- إنشاء التصنيفات الرئيسية والفرعية وتعديلها وحذف التصنيف الخالي.
- إضافة الفوائد وتحريرها وحذفها، مع بيانات المؤلف والكتاب والمجلد والصفحة ولغة النص الأصلي وصاحب الفائدة.
- محرر نصوص يدعم اللصق والتنسيق الأساسي والقوائم والاقتباسات.
- بحث نصي في العنوان والمتن والمؤلف والكتاب وصاحب الفائدة، مع تطبيع عدد من صور الحروف العربية وإزالة التشكيل والتطويل عند البحث.
- لوحة معلومات تعرض الإجمالي، والمضاف اليوم، وهذا الأسبوع، وهذا الشهر، وهذه السنة، والفوائد المستلمة، وتوزيع الفوائد على التصنيفات الرئيسية.
- تسجيل نسخ الترجمة وربطها بالفائدة الأصلية، مع لغة الترجمة واسم المترجم وحالة الترجمة (مسودة/مراجعة/معتمدة). يمكن إدخال اسم/رمز لغة مخصصة أيضًا، ولا تقتصر لغة المحتوى أو الترجمة على لغات واجهة البرنامج الست.
- إنشاء ملف مشاركة بامتداد `.kwb` للفوائد المحددة، يضم التصنيفات اللازمة وترجمات الفوائد.
- استيراد ملفات `.kwb`، وإنشاء التصنيفات والفوائد مع الحفاظ على معرفاتها ومصادرها وترجماتها، وتسجيل اسم المرسل عند إدخاله.
- فتح WhatsApp Web وTelegram Web وMessenger من شاشة التبادل؛ يرفق المستخدم ملف `.kwb` يدويًا داخل تطبيق المراسلة.

## ما الذي لم يكتمل بعد؟

هذا إصدار تأسيسي قابل للاختبار، وليس الإصدار النهائي. توجد نقاط مقصودة في خارطة الطريق:

1. **الترجمة الآلية:** إدارة الترجمات وحفظها ومراجعتها موجودة، لكن لم يتم توصيل مزود ترجمة آلية في هذا الإصدار. سنضيف موصلات قابلة للتبديل بعد اختيار مزود مناسب، مع بيان واضح قبل إرسال النصوص إلى خدمة سحابية.
2. **المرفقات:** لم تُضف بعد إدارة ملفات PDF والصور والمرفقات، ولذلك لا تُضمّن المرفقات في ملفات KWB حاليًا.
3. **معاينة الاستيراد وحل التعارضات يدويًا:** الإصدار الحالي يطابق التصنيفات المتطابقة في الاسم والأب، ويتجاوز الفائدة التي تحمل المعرف نفسه. سنضيف شاشة معاينة وخيارات دمج/احتفاظ/تجاوز أكثر تفصيلًا.
4. **البحث الدلالي والفهرسة المتقدمة:** البحث الحالي نصي محلي، مع تطبيع أولي للعربية. البحث الدلالي متعدد اللغات مرحلة لاحقة.
5. **المزامنة بين الأجهزة والمكتبات المشتركة:** غير مفعّلة بعد؛ البنية الحالية محلية وتمهّد لهذه الإمكانات.
6. **المراجعة الآلية للترجمات والقاموس العلمي متعدد اللغات:** ضمن المراحل اللاحقة.

## تشغيل نسخة التطوير على Windows

### المتطلبات

- Windows 10 أو 11.
- Node.js بإصدار LTS وnpm.
- Rust مع أداة `rustup` واختيار MSVC: `rustup default stable-msvc`.
- Microsoft C++ Build Tools، مع تحديد workload باسم **Desktop development with C++**.
- WebView2 Runtime. غالبًا يكون موجودًا بالفعل على Windows 10 (الإصدار 1803 فأحدث) وWindows 11.

راجع متطلبات Tauri الرسمية قبل تجهيز بيئة التطوير:
https://v2.tauri.app/start/prerequisites/

### التشغيل كتطبيق سطح مكتب

1. فك ضغط المشروع في مجلد عادي.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:

```powershell
npm install
npm run tauri dev
```

أو شغّل `run-dev.bat` بالنقر المزدوج.

### بناء ملف التثبيت

```powershell
npm install
npm run tauri build
```

أو شغّل `build-windows.bat`. ستجد ملفات التثبيت ضمن:

```text
src-tauri/target/release/bundle/nsis/
src-tauri/target/release/bundle/msi/
```

قد يتطلب إنشاء MSI تفعيل ميزة Windows الاختيارية **VBScript** إذا ظهرت رسالة فشل من WiX؛ يمكن عندها بناء NSIS أو تفعيل VBScript وفق دليل Tauri.

## معاينة الواجهة في المتصفح

للمعاينة السريعة دون بناء Tauri:

```powershell
npm install
npm run dev
```

ستفتح الواجهة على `http://127.0.0.1:1420`. وضع المتصفح يستخدم `localStorage` للمعاينة فقط، ولا يستخدم قاعدة SQLite الخاصة بتطبيق سطح المكتب. لا تخلط بين بيانات المعاينة وبيانات نسخة Tauri.

## قاعدة البيانات والخصوصية

- تُنشأ قاعدة SQLite تلقائيًا عند أول تشغيل في مجلد بيانات التطبيق الذي يحدده نظام التشغيل.
- لا يحتاج تشغيل البرنامج أو البحث أو إدارة المكتبة إلى الإنترنت.
- فتح تطبيقات المراسلة يحتاج اتصالًا بالإنترنت.
- الترجمة السحابية، عند إضافتها، ستحتاج اتصالًا بالإنترنت، ويجب أن تكون عبر موصل يمكن للمستخدم ضبطه أو تعطيله.
- ملف `.kwb` في هذا الإصدار ملف JSON منظم بامتداد خاص. لا يحتوي على مرفقات ولا تشفير؛ لا ترسل داخله معلومات حساسة قبل إضافة خيارات التشفير في إصدار لاحق.
- يُنصح بالاحتفاظ بنسخ من ملفات `.kwb` في مكان آمن. لا تحذف مجلد بيانات التطبيق يدويًا.

## ملاحظات الاختبار

البيئة التي أُنشئ فيها هذا المصدر لا تحتوي على Rust/Cargo ولا على اتصال موثوق بمستودع npm؛ لذلك لم أتمكن من إنتاج ملف EXE/MSI أو الادعاء بأن عملية البناء النهائية اجتازت الاختبار هنا. تم التحقق من بنية JSON وملفات الواجهة نحويًا، لكن يجب تنفيذ أول بناء وتشغيل على جهاز Windows مجهز بمتطلبات Tauri، ثم معالجة أي أخطاء بناء تظهر قبل اعتماد النسخة للاستخدام اليومي.

## إضافات الإصدار 0.2.0

- محرر الفائدة يدعم اختيار نوع الخط وحجمه ولون الكتابة ولون تمييز خلفية النص، إلى جانب التنسيقات الأساسية والقوائم والاقتباس.
- صفحة إعدادات للتحكم في ثيم التطبيق: فاتح، داكن، ورقي دافئ، وأخضر هادئ.
- إعداد لتكبير وتصغير النصوص وعناصر الواجهة معًا، مع حفظ التفضيلات محليًا.
- في شاشة تبادل المعرفة، يمكن تحديد جميع فوائد تصنيف رئيسي أو فرعي دفعة واحدة. اختيار التصنيف الرئيسي يشمل فوائده وفوائد جميع تصنيفاته الفرعية. يمكن تكرار العملية لتجميع فوائد من تصنيفات متعددة.
- أزرار WhatsApp وTelegram وMessenger تنشئ ملف المشاركة أولًا ثم تفتح تطبيق/موقع المراسلة. يجب إرفاق ملف KWB يدويًا من مجلد التنزيلات؛ لا يدّعي التطبيق إرسال المرفق تلقائيًا.
- تم الإبقاء على معرّف التطبيق السابق لضمان استمرار الوصول إلى قاعدة بيانات الإصدار 0.1.0. يظهر تحذير لاحقة `.app` على إعدادات Tauri، لكنه لا يمنع بناء Windows؛ سنعالج تغييره لاحقًا عبر ترحيل آمن لبيانات المستخدم.
