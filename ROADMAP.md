# Roadmap

## 0.1 — Foundation (current source release)

- Six-language application shell and RTL/LTR behavior.
- Local SQLite storage.
- Hierarchical categories and benefit CRUD.
- Rich-text entry and lexical search.
- Activity dashboard.
- Translation records and review states.
- Versioned KWB import/export and sender attribution.

## 0.2 — Research workflow

- Import preview and conflict-resolution choices.
- Attachment management and safe KWB packaging.
- More advanced search filters, saved searches and tags.
- Profile/display-name settings and explicit export scopes.
- Translation provider settings and first automatic translation connector after provider selection.

## 0.3 — Translation and discovery

- Translation adapters for selectable providers.
- Preserve original and translation revisions.
- Shared terminology glossary.
- Multilingual semantic search as an optional layer.

## 0.4 — Collaboration

- Research groups and shared libraries.
- Cross-device sync with explicit user consent.
- Library permissions and provenance audit.

All cloud services remain optional. The local library, basic search, editing, import and export should continue to work offline.
