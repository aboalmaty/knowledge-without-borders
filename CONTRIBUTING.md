# Contributing to Knowledge Without Borders

Thank you for your interest in contributing to Knowledge Without Borders (KWB).

Our mission is to build an open, multilingual platform for personal and research knowledge management, preservation, translation, and sharing across borders.

## 1. Ways to Contribute

You can contribute through:

- Reporting bugs and technical issues.
- Suggesting new features and improvements.
- Improving the user interface and accessibility.
- Developing search and knowledge management features.
- Improving Arabic, English, Spanish, French, Chinese, and Urdu support.
- Reviewing translations and terminology.
- Improving documentation and tutorials.
- Testing the application on different operating systems.

## 2. Before Submitting Changes

Please:

1. Check existing Issues and Pull Requests.
2. Describe the problem or proposed improvement.
3. Keep changes focused and clearly documented.
4. Avoid introducing unnecessary dependencies.
5. Never include private user libraries, databases, personal information, API keys, or credentials.

## 3. Development Guidelines

The project currently uses:

- Tauri 2
- React
- JavaScript
- Rust
- SQLite
- Vite

Follow the existing project structure and coding conventions.

Preserve these core principles:

- Local-first data storage.
- Multilingual architecture.
- RTL and LTR support.
- Original content must never be overwritten by translations.
- Knowledge sharing must preserve attribution and source information.
- User data remains under the user's control.

## 4. Translations

Contributions to supported languages are welcome.

Please preserve the meaning and context of the original text.

Do not translate scientific, religious, or technical terminology without considering its intended meaning.

## 5. Pull Requests

When submitting a Pull Request:

- Explain what changed and why.
- Include steps to reproduce or test the change.
- Mention affected languages and platforms.
- Include screenshots for significant interface changes when appropriate.

## 6. Licensing

By submitting a contribution, you agree that your contribution may be distributed under the project's GNU GPL version 3 or any later version, provided that you have the legal right to contribute it.

Do not submit code copied from third-party projects unless its license permits its inclusion.

## 7. Community

Be respectful, constructive, and welcoming.

Knowledge Without Borders is a collaborative project. Every useful contribution helps make knowledge more accessible to researchers around the world.

Thank you for helping us build knowledge without borders.
