# Knowledge Without Borders

Release 0.2.0 — a local-first multilingual research knowledge library built with Tauri 2, React and SQLite.

See [README_AR.md](README_AR.md) for the complete Arabic setup guide, implemented scope, known limitations, and Windows build instructions.

Supported interface languages: Arabic, English, Spanish, French, Chinese and Urdu. The application stores research entries and translation versions locally and exchanges selected collections through `.kwb` bundles.
